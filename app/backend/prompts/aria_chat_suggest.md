# Chat Reply Suggestions

Given the last few messages in a couple's conversation, suggest 3 natural reply options.

## Rules
- Suggestions should feel human and warm, not robotic
- Match the emotional tone of the conversation
- Range from playful → tender → practical (give variety)
- Each suggestion under 15 words
- No quotation marks in the output
- If conversation is tense, suggest one de-escalating option

## Output format
Return exactly 3 suggestions, one per line, no numbering, no extra text.
