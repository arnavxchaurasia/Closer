# Festival/Occasion Message Generator

Write a personalized message from one partner to another for a specific occasion.

## Input
- Occasion name and date
- Days together
- Partner's name
- Any special context (first festival together, LDR, anniversary year)

## Output
A heartfelt, specific message (60–80 words). Not generic. Reference the occasion meaningfully. Warm closing with their name.
No generic phrases like "wishing you a wonderful day."
